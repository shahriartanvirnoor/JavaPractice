আপনার কোডটিতে এরর আসার কারণটি খুবই লজিক্যাল। আপনি সি (C) বা জাভা যে ভাষাতেই কোড লিখুন না কেন, এখানে একটি বেসিক প্রোগ্রামিং কনসেপ্ট কাজ করছে, যেটাকে বলা হয় **Variable Scope (ভ্যারিয়েবলের পরিধি)**।

সহজ করে বুঝিয়ে বলছি কেন আপনার কোডটি কাজ করছে না:

### ১. লোকাল ভ্যারিয়েবল (Local Variable) কী?

আপনার কোডে `test1()` মেথডের ভেতরে `x` এবং `y` ডিক্লেয়ার করেছেন। জাভাতে (এবং সি-তেও) কোনো মেথড বা ফাংশনের ভেতরে যখন কোনো ভ্যারিয়েবল ডিক্লেয়ার করা হয়, তখন সেটি হয় **Local Variable**।

* **নিয়ম:** একটি মেথডের লোকাল ভ্যারিয়েবল শুধুমাত্র ওই মেথডের ব্র্যাকেটের `{ }` ভেতরেই জীবিত থাকে। মেথডটির কাজ শেষ হওয়া মাত্রই ওই ভ্যারিয়েবলগুলো মেমোরি থেকে মুছে যায়।
* তাই `main` মেথড থেকে আপনি যখন `x` বা `y` কে কল করছেন, জাভা সেগুলোকে চিনতে পারছে না। কারণ তারা `test1`-এর ব্যক্তিগত সম্পত্তি।

---

### ২. সমাধান: কীভাবে এটি কাজ করবে?

আপনি যদি চান `test1` এবং `main` দুই মেথডই `x` এবং `y` কে ব্যবহার করবে, তবে তাদের মেথডের ভেতর থেকে বের করে **Class Level**-এ নিয়ে আসতে হবে এবং তাদের আগে **`static`** লিখতে হবে।

সঠিক কোডটি হবে এমন:

```java
public class StaticCheck1 {
    // এগুলো এখন "Static Fields" বা "Class Variables"
    // মেথডের বাইরে ডিক্লেয়ার করায় সবাই এদের চিনবে
    static int x; 
    static int y;

    public static void test1() {
        x = 10; // নতুন করে int লেখার দরকার নেই
        y = 20;
    }
    
    public static void main(String[] args) {
        test1(); // এই মেথডটি কল করলে x ও y এর মান সেট হবে
        System.out.println(x); // এখন কাজ করবে
        System.out.println(y); // এখন কাজ করবে
    }
}

```

---

### ৩. কেন এখানে `static` জরুরি?

আপনি লক্ষ্য করেছেন আমি মেথডের বাইরে `static int x;` লিখেছি। এর কারণ:

* `main` মেথডটি নিজে **static**।
* জাভার নিয়ম অনুযায়ী, একটি **static** মেথড তার বাইরে থাকা কোনো ভ্যারিয়েবলকে তখনই সরাসরি ব্যবহার করতে পারে, যখন ওই ভ্যারিয়েবলটিও **static** হয়।
* আপনি যদি শুধু `int x;` লিখতেন (স্ট্যাটিক ছাড়া), তবে `main` মেথড এরর দিত কারণ সে "অবজেক্ট" ছাড়া নন-স্ট্যাটিক কিছু স্পর্শ করতে পারে না।

### সারসংক্ষেপ:

১. **মেথডের ভেতরে** যা ডিক্লেয়ার করবেন, তা অন্য কেউ পাবে না (পয়েন্টার ছাড়া সি-তেও পেতেন না)।
২. **মেথডের বাইরে (Class Level)** যদি `static` দিয়ে ডিক্লেয়ার করেন, তবে ক্লাসের সব মেথড তাকে সরাসরি চিনবে এবং ব্যবহার করতে পারবে—ঠিক গ্লোবাল ভ্যারিয়েবলের মতো।

এই "স্কোপ" (Scope) বা ভ্যারিয়েবলের সীমানা নিয়ে কি আর কোনো কনফিউশন আছে?
